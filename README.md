# Caso-de-estudio-1-Grupo-11
Repositorio contiene codigo, presentación e informe del caso de estudio 1 de regresión correspondiente al grupo 11. Dicho proyecto se titula "Optimización en la predicción del consumo eléctrico en España (2015-2018)". 

Como correr el codigo:

Se debe descargar la carpeta "Codigo grupo 11" y correr el codigo desde esa misma carpeta
dado que el codigo requiere en una misma ruta una carpeta llamada "datos" que incluye el dataset


El codigo deberia correr sin problemas, descarga las librerias necesarias y busca solo el dataset, luego
al terminar agrega una carpeta "resultados" que incluye graficos y tablas de resultados y comparaciones
